## About

Crash Detection System explores computer-vision techniques for identifying crash-related events from camera or video input. The repository is intended as a software and research prototype for road-safety monitoring. It focuses on the detection workflow rather than presenting itself as a production-ready safety system.

## Features

- ✅ Crash-event detection workflow
- ✅ Camera/video input processing
- ✅ Computer-vision based analysis
- ✅ Foundation for real-time road-safety monitoring
